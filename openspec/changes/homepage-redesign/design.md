## Context

当前 HomePage 是 97 行的占位页，仅展示 "首页功能开发中" 文字和 3 个预告标签。应用已有完整的宇宙星空视觉体系（DynamicBackground 深色渐变 + 毛玻璃卡片 + 紫色品牌色 #5C6BC0），LearningHome 已承载课程列表功能，ProfilePage 已承载个人中心功能，BottomTabBar 已实现 4-Tab 导航。

**约束条件：**
- 单文件 ≤300 行（ARCHITECTURE_CONVENTIONS）
- 严禁硬编码中文用户文案，必须使用 `$r()` 资源引用
- 最小可点击区域 44vp × 44vp
- 组件内仅用 @Prop 展示型传递
- 首屏加载时间 <2s（PERFORMANCE_CONVENTIONS）
- 动画 animateTo ≤500ms（PERFORMANCE_CONVENTIONS）

## Goals / Non-Goals

**Goals：**
- 打造具有"不背单词"级视觉吸引力的学习仪表盘首页
- 提供清晰的学习路径引导（今日任务 → AI 推荐 → 快捷操作）
- 展示用户学习数据，形成正向激励反馈循环
- 与现有宇宙星空/毛玻璃风格保持一致
- 响应式布局适配手机屏幕（375-414vp）

**Non-Goals：**
- 不实现服务端推送的每日问题（当前用本地 mock）
- 不实现社交/社区功能（发现区仅展示模板推荐）
- 不实现复杂的图表库依赖（统计用简单 Canvas 或纯 UI 组件）
- 不修改 LearningHome 的课程列表逻辑

## Decisions

### D1: 页面布局 — 自上而下信息漏斗

**选择**：6 层纵向堆叠，信息密度递减

```
L1 品牌问候 (紧凑)     → 建立情感连接
L2 今日学习卡 (核心)    → 主 CTA，最醒目
L3 AI 每日一问 (吸引)   → 差异化亮点
L4 快捷操作 (工具)      → 高频入口
L5 数据概览 (激励)      → 正向反馈
L6 发现推荐 (探索)      → 延长停留
```

**理由**：
- 符合移动端"F型"阅读模式——左上角最重要
- 核心操作（继续学习）在首屏可见区域
- 渐进式信息披露，避免认知过载

**替代方案**：左右分栏/Tab 切换 → 手机屏幕宽度不足，拒绝

### D2: 数据来源 — HomeViewModel 聚合查询

**选择**：HomeViewModel 新增 `loadDashboardData()` 方法，聚合 course/question_record/ai_request_log 三表数据

**理由**：
- 复用现有 ViewModel 架构，符合 MVVM 分层
- 数据计算集中在 VM 层，页面只做展示
- 支持后续从 mock 切换到真实 DB 查询

**替代方案**：AppStorage 直接读取 → 违反分层规范，拒绝

### D3: 视觉风格 — 宇宙星空增强版

**选择**：保留 DynamicBackground + 在其上叠加半透明内容层，关键模块使用毛玻璃卡片（rgba(255,255,255,0.06)），核心 CTA 使用渐变按钮

**理由**：
- 与 LearningHome/ProfilePage 保持一致的品牌识别度
- 深色背景上的发光元素（环形进度、渐变按钮）有强视觉冲击力
- 参考截图中的"不背单词"风格：深色底+发光卡片+圆润UI

### D4: 今日学习卡片 — 环形进度 + 步骤条

**选择**：Canvas 绘制环形进度条（0~100%）+ 三问步骤指示器（Q1/Q2/Q3 进度点）+ "继续学习"大按钮

**理由**：
- 环形进度是学习类 App 的标准范式（Duolingo/不背单词）
- 三问步骤可视化强化方法论品牌
- Canvas 绘制性能可控（单次绘制，非动画）

### D5: AI 每日一问 — 卡片式对话入口

**选择**：独立卡片，含问题标题、来源课程标签、"开始思考"CTA 按钮，点击跳转 AIChatPanel

**理由**：
- 将 AI 能力显性化，区别于普通学习 App
- 每日更新机制增加日活粘性
- 卡片形式与整体 UI 一致

## Risks / Trade-offs

| 风险 | 缓解措施 |
|------|---------|
| HomePage 行数超 300 | 严格拆分 6 个子组件，主页面仅做 Stack+Scroll 编排 |
| 首屏渲染慢（Canvas+多组件） | L1-L3 优先渲染，L4-L6 LazyForEach 延迟 |
| 无真实数据时体验差 | 提供 mock 数据降级方案，字段全部有默认值 |
| 暗色模式下文字可读性 | 使用白色(0.85)/浅灰(0.6)/暗灰(0.4) 三级对比度 |
| 国际化文案量大 | 所有文案走 string.json，中英文双份 |
